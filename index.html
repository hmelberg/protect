protect

Statistical disclosure control for tabular data and analytical results — 17 single-token verbs, pure numpy + pandas.

Open Playground → View on GitHub

What it does

protect separates two protection layers explicitly:

  • Data protection — transforms applied to microdata before release (noise, binning, ID replacement, date coarsening, category collapsing).
  • Result protection — transforms applied to outputs (cell suppression on tables, CI widening on regressions, hex-bin suppression on plots).

Both are first-class. The verb suppress covers result protection; every other data-side verb covers data protection.

Quick start

import protect as p

# A single verb
df = p.winsorize(df, "income", limits=(0.01, 0.99))

# Many verbs at once with an audit trail
df_safe, log = p.protect(df, unit_id="pid", recipe={
    "income":  {"winsorize": {"limits": (0.01, 0.99)}},
    "dob":     {"year":      {"bin": 5}},
    "visit":   {"diff":      {"ref": "first_per_unit"}},
    "icd":     {"shorten":   {"sep": ".", "min_count": 5}},
    "country": {"collapse":  {"rare_below": 5}},
    "pid":     {"pseudonymize": {"method": "random"}},
})

# Named composition for HIPAA Safe Harbor
df_safe, log = p.profile(df, "safe_harbor",
                         date_cols=["dob"], zip_col="zip", id_cols=["pid"])

# Risk assessment
print(p.risk(df_safe, quasi_ids=["sex", "zip", "country"], unit_id="pid").describe())

Try it in the browser

The playground runs protect entirely in your browser via Pyodide — no installation, no server. A sample 200-patient panel dataset is preloaded; click any verb in the sidebar to drop in a working example.

First load takes ~10-20s while Pyodide and pandas download (~20 MB, cached after).

pip install -e .
